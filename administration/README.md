# Administration

Module d'administration fonctionnelle, paramètres, journal, pilotage et exports.

Accès réservé aux utilisateurs `is_staff`.

Services :

- `administration_service` — paramètres, supervision
- `securite_service` — plafonds, maintenance, validations
- `journal_service` — journalisation des actions admin
- `dashboard_service` / `statistiques_service` / `rapport_service` — pilotage
- `export_service` — exports CSV / JSON
